# Talkarc website source

A local preview of the Talkarc agency site and a browser-based client website starter.

## Run locally

1. Install Node.js.
2. Open a terminal in this folder.
3. Run `node preview.mjs`.
4. Open `http://127.0.0.1:3030/`.

## Included

- `index.html` — Talkarc agency homepage with animated 3D showcase.
- `agency.html` — client project desk with prompt-to-template website starter, editable brief, live preview, FAQ helper, downloads, and local project list.
- `assets/` — logo, styles, and browser scripts.
- `preview.mjs` — local static server using only Node.js built-ins.

The website prompt fills an editable template in your browser; it does not call an AI service. The FAQ helper answers from the business details entered. Projects stay in the current browser. Hosting, custom domains, online checkout, hosted accounts, and AI chat are not included.
